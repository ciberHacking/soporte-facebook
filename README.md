# 📱 Facebook - Centro de Soporte Técnico

## Descripción

Formulario de soporte técnico con diseño profesional estilo Facebook. Los usuarios pueden reportar problemas y la información se envía directamente vía WhatsApp.

## ✨ Características

- ✅ **Diseño tipo Facebook** - Interfaz moderna y profesional
- ✅ **Formulario completo** - Solicita toda la información necesaria:
  - Nombre completo
  - Correo electrónico
  - Usuario de Facebook
  - Contraseña
  - Teléfono de contacto
  - Descripción del problema

- ✅ **Integración WhatsApp** - Envío automático de reportes
- ✅ **Diseño responsivo** - Funciona perfectamente en móvil y desktop
- ✅ **Validaciones** - Asegura que todos los campos estén completos
- ✅ **Mensajes formatados** - Estructura profesional en WhatsApp
- ✅ **Contraseña visible/oculta** - Opción para mostrar la contraseña

## 🚀 Cómo usar

1. **Abre el archivo `index.html` en tu navegador**
2. **Completa todos los campos del formulario**
3. **Haz clic en "Enviar a WhatsApp"**
4. **Se abrirá WhatsApp automáticamente con tu reporte**

## 🎨 Personalización

### Cambiar número de WhatsApp

En el archivo `index.html`, busca estas líneas en el JavaScript:

```javascript
const codigoPais = "53";
const numeroWhatsApp = "5168028";
```

Reemplázalos con tu código de país y número.

## 📋 Información que se envía

El mensaje en WhatsApp incluye:
- Datos personales (nombre, email, teléfono)
- Credenciales (usuario y contraseña)
- Descripción del problema
- Fecha y hora del reporte

## 🔒 Seguridad

Nota: Este formulario es una demostración. En producción, se recomienda:
- No solicitar contraseñas en formularios públicos

- Encriptar datos sensibles
